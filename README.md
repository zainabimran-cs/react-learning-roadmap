# React Learning Roadmap Dashboard

## About the Project

The React Learning Roadmap Dashboard is a web application that helps users explore React topics through a sidebar and interactive topic examples.

Users can open topics, view explanations and working examples, mark topics as completed, and track their learning progress.

## Features

- Login and logout functionality
- Protected routes for dashboard access
- Sidebar navigation for React topics
- Interactive examples for different React concepts
- Mark topics as completed
- Display completed topics on the Home page
- Track total, completed, and pending topics
- Code splitting using React.lazy() and Suspense
- Responsive layout using Tailwind CSS
- Next and previous buttons to navigate between React topics

## Technologies Used

- React
- Vite
- JavaScript
- React Router DOM
- Tailwind CSS
- Font Awesome
- ESLint

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/zainabimran-cs/react-learning-roadmap.git
```

### 2. Open the Project Folder

```bash
cd dashboard
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

Open the local URL shown in the terminal to view the application.

## Production Build

To create a production build, run:

```bash
npm run build
```

## Code Quality Check

To check the code for lint errors and warnings, run:
